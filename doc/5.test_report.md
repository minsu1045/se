# 테스트 결과 보고서

## 1. 서론

### 1.1 문서 목적 및 범위

본 문서는 클라우드 파일 공유 시스템 **Mini Drive**에 대한 테스트를 수행하고 그 결과를 정리한 문서이다.

본 문서에서는 Mini Drive의 테스트 기준, 테스트 범위, 테스트 케이스와 테스트 결과를 명시한다.

### 1.2 프로젝트 개요

Mini Drive는 조직 내부 사용자를 위한 클라우드 기반 파일 관리 및 공유 시스템이다. 사용자는 웹 브라우저를 통해 파일 업로드, 다운로드, 공유, 검색, 버전 관리 등의 기능을 사용할 수 있다.

### 1.3 용어 정의

| 용어 | 설명 |
|---|---|
| 블랙박스 테스트 | 시스템 내부를 모른다는 가정 하에 사용자 시점에서 수행하는 테스트 |
| 테스트 케이스 | 특정 기능을 검증하기 위해 설계된 입력값, 실행 조건, 예상 결과의 집합 |
| SUCCESS | 테스트 결과가 예상 결과와 일치하는 경우 |
| FAIL | 테스트 결과가 예상 결과와 일치하지 않는 경우 |
| YES | 해당 조건을 만족하는 경우 |
| NO | 해당 조건을 만족하지 않는 경우 |

### 1.4 참조 문서

- 요구사항 정의서: `doc/3.requirements.md`
- 요구사항 분석서: `doc/4.requirements_analysis.md`

## 2. 테스트 개요

### 2.1 테스트 범위

테스트는 시스템 내부를 모른다는 가정 하에 블랙박스 테스트로 이루어진다.

| 범위 | 내용 |
|---|---|
| 인증 기능 | 로그인 동작 정확성 확인 및 요구사항 충족 확인 |
| 파일 관리 기능 | 파일 업로드, 다운로드, 폴더 관리 동작 정확성 확인 |
| 공유 기능 | 파일 공유 및 외부 링크 생성 동작 정확성 확인 |
| 검색 기능 | 파일 검색 동작 정확성 확인 |
| 보안 기능 | 권한 제어 및 접근 제한 동작 정확성 확인 |

### 2.2 테스트 항목 및 통과 기준

| 기능별 테스트 항목 | 통과 기준 |
|---|---|
| 로그인 기능 | 올바른 이메일과 비밀번호만 로그인에 성공한다 |
| 파일 업로드 기능 | 선택한 파일이 시스템에 정상적으로 저장된다 |
| 파일 다운로드 기능 | 저장된 파일이 정상적으로 다운로드된다 |
| 폴더 관리 기능 | 폴더 생성, 이름 변경, 삭제가 정상적으로 동작한다 |
| 파일 공유 기능 | 공유 설정한 사용자만 파일에 접근할 수 있다 |
| 외부 링크 생성 기능 | 링크 생성 및 만료 기간 설정이 정상적으로 동작한다 |
| 파일 검색 기능 | 검색 조건에 맞는 파일 목록이 정상적으로 출력된다 |

| 비기능별 테스트 항목 | 통과 기준 |
|---|---|
| 브라우저 호환 테스트 | Chrome, Edge 등 주요 브라우저에서 정상적으로 동작한다 |
| 보안 테스트 | 로그인하지 않은 사용자가 시스템을 이용할 수 없다 |
| 성능 테스트 | 파일 검색 결과가 3초 이내에 출력된다 |

## 3. 테스트 케이스

### 3.1 테스트 케이스 선정

테스트 케이스는 2.2의 기능별 테스트 항목에 따라 선정하였으며, 블랙박스 테스트 기법을 기반으로 사용자 시점 테스트 케이스 선정에 중점을 둔다.

### 3.2 테스트 케이스 유형

- 문자열 입력 테스트 케이스: 로그인, 파일 업로드 등 입력 기능 검증
- 동작 테스트 케이스: 파일 관리, 공유, 검색 기능 동작 확인
- 보안 테스트 케이스: 권한 제어 및 접근 제한 확인

## 4. 테스트 예외사항

### 4.1 중단 기준과 재개 조건

| 중단 기준 | 재개 조건 |
|---|---|
| 시스템 input type과 다른 input이 입력되었을 때 | 입력을 중단하고 기존 데이터로 시스템을 재개한다 |
| 파일 업로드 중 네트워크 오류가 발생했을 때 | 오류 메시지를 출력하고 업로드를 재시도할 수 있도록 한다 |
